# Temperature & Humidity Monitor PCB

A custom PCB designed in KiCad that displays temperature and humidity data from a DHT22 sensor on an OLED display. The project uses an Arduino Nano as the main controller and includes a 10-segment LED bar graph for visual indicators, based on the temperature and humidity.

## Components


- Arduino Nano
- DHT22 Temperature/Humidity Sensor
- 0.96" 128x64 I2C OLED Display
- 10-Segment LED Bar Graph
- 10 x 220Ω Resistors
- Custom PCB

## Why I Built This

I wanted to learn the complete PCB design process, from creating a schematic to designing a PCB and viewing the final board in 3D. This project also helped me practice working with sensors, displays, and KiCad.The project also would have a real purpose in my life because it helps my to manage my skin, eye, and nose health.
